# Element: Natural Energy Launch

Crie um website institucional/apresentação premium para a marca fictícia de bebida energética natural ELEMENT.

IMPORTANTE:
Este site é um projeto acadêmico de empreendedorismo interdisciplinar envolvendo Química, Física, Biologia e Empreendedorismo. O objetivo é apresentar a empresa, seus produtos, sua proposta científica e seu plano de negócios de maneira extremamente profissional.

NÃO quero um site tradicional com várias páginas.
NÃO quero menu que leve para outras páginas.
NÃO quero uma estrutura de e-commerce.
NÃO quero excesso de botões.

Quero uma experiência de apresentação vertical contínua, como uma landing page premium de uma marca de energético: o usuário simplesmente rola para baixo e a história da Element vai sendo apresentada em seções cinematográficas, fluidas e visualmente impactantes.

O site precisa funcionar perfeitamente em DESKTOP, E CELULAR, com atenção especial ao mobile.
